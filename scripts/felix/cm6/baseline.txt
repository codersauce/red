# - "%p and shell error text: Helix reports the absolute path and `sh:`;
#   Red reports the document name and `/bin/sh:`.
# - Devanagari conjuncts (scripts#*): unicode-segmentation 1.12 steps back

#   Red corrects those boundaries.
# - Insert-mode Ctrl-C leaves Insert in Red; Helix inserts `c`.
# - Language suites (md:*, code:*): the oracle builds only the grammars of
#   the case languages, so Helix sees Markdown code fences and inline text
#   without injections that Red parses. Red's tree-sitter indent queries also
#   differ from Helix's in some Enter, `o` and linewise `c` cases.
# - Rust cases whose markup contains `#[` make Helix's markup parser panic;
#   they are skipped.
